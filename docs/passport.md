**Проблема:** Ручное управление освещением и климатом приводит к перерасходу ресурсов и неудобству.
**Цель:** Создать ООП-агента, который анализирует данные датчиков и автоматизирует рутину.
**Задачи:** 
1. Собрать синтетические данные.
2. Спроектировать классы.
3. Реализовать логику реагирования.
**Продукт:** Модуль, обрабатывающий события умного дома.
**Ограничения:** Работа только с синтетическими данными, без реального API.
